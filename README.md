# x-ui-inbounds-setup
Автоматическая настройка инбаундов Trojan-gRPC и Hysteria2 для панели 3X-UI. Исправляет баг с localhost в ссылках, применяет эталонные шаблоны конфигурации, настраивает UFW с комментариями и добавляет маскировку через Nginx (grpcs://) одной командой.

# 🚀 x-ui-inbounds-setup

Автоматический скрипт для развёртывания и настройки входящих подключений (inbounds) **Trojan-gRPC** и **Hysteria2** на серверах с панелью **3X-UI**.

## 🐛 Проблема

Ручное создание инбаундов в 3X-UI часто приводит к ошибкам:
- Неправильные параметры TLS/ALPN или fingerprint, из-за чего протоколы не работают или легко блокируются.
- Баг панели, при котором в share-ссылках генерируется `localhost` вместо реального домена.
- Отсутствие правил в брандмауэре (UFW) или забытые порты.
- Сложная ручная настройка маскировки Trojan через Nginx (порт 443) с использованием `grpcs://`.

## ✅ Решение

Скрипт автоматически выполняет полную настройку за один запуск:
1. **Определяет домен** из конфигурации Nginx или базы данных панели.
2. **Исправляет баг с `localhost`**, принудительно прописывая правильный `webDomain` в настройках панели.
3. **Создаёт или обновляет инбаунды** по проверенным эталонным шаблонам (сохраняя существующих клиентов, если они уже есть).
4. **Настраивает UFW**, открывая нужные порты с понятными комментариями (`# Trojan-gRPC Auto`, `# Hysteria2 Auto`).
5. **Патчит Nginx**, добавляя правильный `location` с `grpcs://` для бесшовной маскировки Trojan-трафика под обычный HTTPS на 443 порту.

## 🚀 Установка одной командой

```bash
bash <(wget -qO- https://raw.githubusercontent.com/Michael-K-cloud/x-ui-inbounds-setup/main/setup-inbounds.sh)
```

## 📋 Что делает скрипт (пошагово)

1. **Шаг 1. Проверка окружения**  
   Скрипт проверяет права `root` и наличие установленной службы `x-ui.service`.

2. **Шаг 2. Определение домена и фикс `webDomain`**  
   Автоматически находит ваш домен. Останавливает панель, выполняет SQL-запрос `UPDATE settings SET value='<домен>' WHERE key='webDomain';` и запускает панель обратно. Это гарантирует, что все новые share-ссылки будут содержать правильный домен, а не `localhost`.

3. **Шаг 3. Умное создание инбаундов**  
   - Проверяет базу данных `/etc/x-ui/x-ui.db`.
   - Если клиенты для Trojan или Hysteria уже существуют (например, их добавил установщик или бот), скрипт **сохраняет их**.
   - Если база пуста, создаёт одного временного клиента для валидности JSON-конфигурации.
   - Вставляет инбаунды со строгими эталонными параметрами:
     - **Trojan:** gRPC, TLS 1.2/1.3, ALPN `h2, http/1.1`, fingerprint `chrome`, `externalProxy`.
     - **Hysteria2:** TLS 1.3, ALPN `h3`, fingerprint `firefox`, `udpIdleTimeout: 60`.

4. **Шаг 4. Настройка брандмауэра (UFW)**  
   Автоматически открывает сгенерированные порты с понятными комментариями:
   - `ufw allow <порт>/tcp comment "Trojan-gRPC Auto"`
   - `ufw allow <порт>/udp comment "Hysteria2 Auto"` *(критично для работы Hysteria)*

5. **Шаг 5. Патч Nginx для маскировки**  
   Добавляет в `/etc/nginx/snippets/includes.conf` блок `location` для `serviceName` Trojan, используя `grpcs://` для повторного шифрования трафика до Xray. Делает бэкап конфига перед изменением и проверяет синтаксис через `nginx -t`.

6. **Шаг 6. Финальный вывод**  
   Выводит в консоль готовые ссылки для подключения (как для прямого порта, так и для маскировки через 443), чтобы вы могли сразу проверить работу или добавить их в бота.

## ⚙️ Требования

- **ОС:** Ubuntu 22.04 / 24.04
- **Права:** `root`
- **Панель:** Установленная 3X-UI (например, через `mozaroc/x-ui-pro`)
- **SSL:** Для домена уже должен быть выпущен валидный сертификат (Let's Encrypt), который панель сохранила в `/root/cert/<домен>/`

---

## 🛡️ Безопасность

- Скрипт **не удаляет** существующих клиентов из базы данных, он только обновляет структуру инбаунда до эталонной.
- Перед изменением конфигурации Nginx автоматически создаётся бэкап с меткой времени.
- Скрипт не содержит и не передаёт конфиденциальные данные (пароли генерируются локально и остаются на сервере).
- Все изменения применяются только после успешной проверки `nginx -t`.
