# x-ui-inbounds-setup
Автоматическая настройка инбаундов Trojan-gRPC и Hysteria2 для панели 3X-UI. Исправляет баг с localhost в ссылках, применяет эталонные шаблоны конфигурации, настраивает UFW с комментариями и добавляет маскировку через Nginx (grpcs://) одной командой.

# 🚀 x-ui-inbounds-setup

Автоматический скрипт для развёртывания и настройки входящих подключений (inbounds) **Trojan-gRPC** и **Hysteria2** на серверах с панелью **3X-UI**.

## 🐛 Проблема

Ручное создание инбаундов в 3X-UI часто приводит к ошибкам:
- Неправильные параметры TLS/ALPN или fingerprint, из-за чего протоколы не работают или легко блокируются.
- Баг панели, при котором в share-ссылках генерируется `localhost` вместо реального домена.
- Отсутствие правил в брандмауэре (UFW) или забытые порты.
- Сложная ручная настройка маскировки Trojan через Nginx (порт 443) с использованием `grpcs://`.

## ✅ Решение

Скрипт автоматически выполняет полную настройку за один запуск:
1. **Определяет домен** из конфигурации Nginx или базы данных панели.
2. **Исправляет баг с `localhost`**, принудительно прописывая правильный `webDomain` в настройках панели.
3. **Создаёт или обновляет инбаунды** по проверенным эталонным шаблонам (сохраняя существующих клиентов, если они уже есть).
4. **Настраивает UFW**, открывая нужные порты с понятными комментариями (`# Trojan-gRPC Auto`, `# Hysteria2 Auto`).
5. **Патчит Nginx**, добавляя правильный `location` с `grpcs://` для бесшовной маскировки Trojan-трафика под обычный HTTPS на 443 порту.
